# Convert imported glTF materials to Unity Standard

This version converts every material generated by glTFast after the GLB hierarchy is instantiated.
The converted materials use Unity's Built-in Render Pipeline `Standard` shader.

## Files changed

- `Runtime/RuntimeModAssetImporter.cs`
- `Runtime/RuntimeStandardMaterialConverter.cs` (new)

## Inspector setup

Select the GameObject containing `RuntimeModAssetImporter`.

- Enable `Convert Imported Materials To Standard`.
- Assign the built-in `Standard` shader to `Standard Shader`.
- Keep `Repack Metallic Roughness Texture` enabled for correct glTF metal/roughness channel conversion.
- Keep `Repack Occlusion Texture` enabled because glTF stores occlusion in the red channel while Standard reads it from green.

If you do not assign the shader, the code falls back to `Shader.Find("Standard")`. For builds, assigning it directly or adding `Standard` to **Project Settings > Graphics > Always Included Shaders** is safer.

## Import order

1. glTFast loads and instantiates the GLB.
2. All child `Renderer.sharedMaterials` are inspected.
3. Each unique glTF material is converted once.
4. Renderers are reassigned to the converted Standard materials.
5. The normal mod-import completion callback runs.

## Copied properties

- base color and base color texture
- metallic factor
- roughness converted to Standard smoothness
- metallic/roughness texture repacked to Standard metallic/gloss format
- normal texture and scale
- emission texture and color
- occlusion texture and strength
- opaque, alpha cutout, and transparent rendering modes
- double-sided culling

## Important

Unity's `Standard` shader is for the Built-in Render Pipeline. Do not use this option in URP or HDRP. For URP, convert to `Universal Render Pipeline/Lit` instead.
